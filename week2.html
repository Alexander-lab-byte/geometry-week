Vector coordinates and length

a = (−2; 3), b = (1; −1). Find the coordinates and length of each vector.

  1. Rule: multiply each coordinate by the number, then add coordinates. Length: |(x; y)| = √(x² + y²).
  2. a) 2a − b = (−4; 6) − (1; −1) = (−5; 7), length √(25 + 49) = √74.
  3. b) ½a + b = (−1; 1.5) + (1; −1) = (0; ½), length ½.
  4. c) −½a + ⅓b = (1; −1.5) + (⅓; −⅓) = (4/3; −11/6).
  5. Length: √(16/9 + 121/36) = √(64/36 + 121/36) = √185 / 6.
a) (−5; 7), √74 · b) (0; ½), ½ · c) (4/3; −11/6), √185/6
02

Vector between two points

A(1; −1), B(3; 1), C(−1; 2). Find the coordinates and length.

  1. Rule: AB = (end − start) = (x_B − x_A; y_B − y_A).
  2. a) AB = (3 − 1; 1 − (−1)) = (2; 2), |AB| = √8 = 2√2.
  3. b) BC = (−1 − 3; 2 − 1) = (−4; 1), |BC| = √17.
  4. c) CA = (1 − (−1); −1 − 2) = (2; −3), |CA| = √13.
  5. Check: AB + BC + CA = (0; 0) ✓ (closed triangle).
AB = (2; 2), 2√2 · BC = (−4; 1), √17 · CA = (2; −3), √13
03

Find k and point C

A(−1; 0), B(2; −1), AC = k·AB, k > 0, |AC| = 20.

  1. AB = (2 − (−1); −1 − 0) = (3; −1), |AB| = √10.
  2. |AC| = |k|·|AB| → 20 = k·√10 → k = 20/√10 = 2√10.
  3. AC = 2√10·(3; −1) = (6√10; −2√10).
  4. C = A + AC = (−1 + 6√10; −2√10) ≈ (17.97; −6.32).
k = 2√10 ≈ 6.32 · C(−1 + 6√10; −2√10)
04

Dot products in a regular hexagon

ABCDEF is a regular hexagon, AB = 2. Find the dot products.

  1. Rule: u·v = |u|·|v|·cos φ. In a regular hexagon each inner angle is 120°, short diagonal = 2√3, long diagonal = 4.
  2. a) AB·AF: |2|·|2|·cos120° = 4·(−½) = −2.
  3. b) AC·AE: triangle ACE is equilateral, so φ = 60°. (2√3)²·½ = 6.
  4. c) BC·FB: ∠FBC = 120° − 30° = 90°, so the vectors are perpendicular → 0.
  5. d) AD·EF: AD ∥ EF, but they point in opposite directions (φ = 180°). 4·2·(−1) = −8.
a) −2 · b) 6 · c) 0 · d) −8
05

Angle between vectors

Find the angle between the vectors.

  1. Rule: cos φ = (a·b) / (|a|·|b|), with a·b = x₁x₂ + y₁y₂.
  2. a) (1; 3), (4; 2): a·b = 4 + 6 = 10, |a||b| = √10·√20 = 10√2 → cos φ = 1/√2 → 45°.
  3. b) (1; 2), (1; −3): a·b = 1 − 6 = −5, |a||b| = √5·√10 = 5√2 → cos φ = −1/√2 → 135°.
  4. c) (2; 3), (−2; −3): b = −a, opposite directions → cos φ = −1 → 180°.
  5. d) (1 + √3; 2), (1 − √3; 1): a·b = (1 − 3) + 2 = 0 → 90°.
a) 45° · b) 135° · c) 180° · d) 90°
06

Diagonal of a parallelogram

ABCD is a parallelogram, AB = 1, AD = 3, ∠BAD = 2π/3. Find AC.

  1. AC = AB + AD (parallelogram rule).
  2. |AC|² = AB² + AD² + 2·AB·AD.
  3. AB·AD = 1·3·cos120° = −3/2.
  4. AC² = 1 + 9 + 2·(−3/2) = 10 − 3 = 7 → AC = √7.
AC = √7 ≈ 2.65
07

Perpendicular vectors

a = (2; −1), b = (k − 1; k). Find k so that a ⊥ b.

  1. Perpendicular ⇔ dot product is 0: a·b = 0.
  2. 2(k − 1) + (−1)·k = 0 → 2k − 2 − k = 0 → k = 2.
  3. Check: b = (1; 2), and (2)(1) + (−1)(2) = 0 ✓
k = 2
08

Centroid with vectors

A(1; 2), B(−2; −3), C(−1; 4). G is the centroid. Express OG and find G.

  1. The centroid divides each median 2 : 1, which gives OG = ⅓(OA + OB + OC).
  2. OA + OB + OC = (1 − 2 − 1; 2 − 3 + 4) = (−2; 3).
  3. G = ⅓(−2; 3) = (−2/3; 1).
OG = ⅓(OA + OB + OC), G(−2/3; 1)
09

Tetrahedron and centroid

OABC is a tetrahedron, G is the centroid of △ABC, OA = a, OB = b, OC = c.

  1. a) Same rule as problem 8, from point O: OG = ⅓(a + b + c).
  2. b) AB = b − a. Show OG·AB = 0.
  3. OG·AB = ⅓(a + b + c)·(b − a) = ⅓(|b|² − |a|² + c·b − c·a).
  4. In a regular tetrahedron all edges are equal: |a| = |b|, and c·b = c·a (both = |a|²·cos60°).
  5. So every bracket is 0 → OG·AB = 0 → OG ⊥ AB ∎
a) OG = ⅓(a + b + c) · b) OG·AB = 0, so OG ⊥ AB

Part b) is only true when OA = OB and ∠AOC = ∠BOC, for example in a regular tetrahedron. The problem means that case.

Proof: MA + MB + MC = 0

M is the centroid of △ABC. Prove the sum of vectors is zero.

  1. Take any origin O. Centroid rule: OM = ⅓(OA + OB + OC).
  2. MA = OA − OM, MB = OB − OM, MC = OC − OM.
  3. Sum: (OA + OB + OC) − 3OM = 3OM − 3OM = 0 ∎
MA + MB + MC = 0 (proved)

Area from coordinates

A(−2; 4), B(3; 2), C(2; −3). Find the area of △ABC.

  1. AB = (5; −2), AC = (4; −7).
  2. Area rule: S = ½·|x₁y₂ − x₂y₁| for the two vectors.
  3. x₁y₂ − x₂y₁ = 5·(−7) − 4·(−2) = −35 + 8 = −27.
  4. S = ½·27 = 13.5.
S = 13.5
12

Three points on one line

A(−1; −3), B(0; −2a), C(3a; a) are on one line. Find a.

  1. Collinear ⇔ AB ∥ AC ⇔ x₁y₂ − x₂y₁ = 0.
  2. AB = (1; 3 − 2a), AC = (3a + 1; a + 3).
  3. 1·(a + 3) − (3 − 2a)(3a + 1) = a + 3 − (7a + 3 − 6a²) = 6a² − 6a = 0.
  4. 6a(a − 1) = 0 → a = 0 or a = 1.
  5. a = 0 gives B = C = (0; 0), two points in the same place, so it is not three real points.
a = 1 (a = 0 makes B and C the same point)

Triangle from the picture

BE = ED = DC, AC ⊥ y-axis, E(0; −3), D(2; 0). Find the area of △ABC.

  1. B, E, D, C are on one line with equal steps, so each step is ED = (2; 3).
  2. C = D + (2; 3) = (4; 3), B = E − (2; 3) = (−2; −6).
  3. AC ⊥ y-axis → AC is horizontal, and A is on the y-axis → A(0; 3).
  4. Base AC = 4. Height = distance from B to the line y = 3: 3 − (−6) = 9.
  5. S = ½·4·9 = 18.
S = 18

Length and perpendicular in 3D

v = (6; a; b), u = (3; 2; 2), |v| = 21, v ⊥ u.

  1. Length: 36 + a² + b² = 441 → a² + b² = 405.
  2. Perpendicular: 18 + 2a + 2b = 0 → a + b = −9.
  3. ab = ((a + b)² − (a² + b²))/2 = (81 − 405)/2 = −162.
  4. a and b are roots of t² + 9t − 162 = 0 → t = 9 or t = −18.
(a; b) = (9; −18) or (−18; 9)

Vectors in space

OA = (2; 1; −2), OB = (5; −1; k), OC = (2; 6; −3).

  1. a) ∠AOB = 90° ⇔ OA·OB = 0: 10 − 1 − 2k = 0 → k = 4.5.
  2. b) AB = (3; −2; k + 2), |OC|² = 4 + 36 + 9 = 49. So 9 + 4 + (k + 2)² = 49 → (k + 2)² = 36 → k = 4 or k = −8.
  3. c) |OA| = 3, so OD = (9/3)·OA = (6; 3; −6). |OC| = 7, so OE = (14/7)·OC = (4; 12; −6).
  4. DE = OE − OD = (−2; 9; 0) → |DE| = √(4 + 81) = √85.
a) k = 4.5 · b) k = 4 or −8 · c) |DE| = √85

Collinear vectors

a = (x; −2; 2), b = (3; y; 1) are collinear. Find x·y.

  1. Collinear ⇔ a = t·b.
  2. Third coordinate: 2 = t·1 → t = 2.
  3. x = 2·3 = 6, −2 = 2y → y = −1.
  4. x·y = 6·(−1) = −6.
x·y = −6
17

Parallel vectors, find p and q

a = (−18; p; 3p), b = (151; p − 39; 148), c = (p − 6; 3; q), (b − a) ∥ c.

  1. b − a = (169; −39; 148 − 3p).
  2. Parallel ⇔ coordinates are proportional. Middle pair: −39/3 = −13.
  3. 169/(p − 6) = −13 → p − 6 = −13 → p = −7.
  4. Third: (148 − 3p)/q = −13 → 169/q = −13 → q = −13.
  5. Check: b − a = (169; −39; 169) = −13·(−13; 3; −13) ✓
p = −7, q = −13

Cosine of an angle in 3D

A(−1; −1; −3). B and C are on the Oy axis, √26 away from A. Find cos∠(AB, AC).

  1. A point on Oy is (0; y; 0). Distance²: 1 + (y + 1)² + 9 = 26 → (y + 1)² = 16.
  2. y = 3 or y = −5 → B(0; 3; 0), C(0; −5; 0).
  3. AB = (1; 4; 3), AC = (1; −4; 3), both length √26.
  4. AB·AC = 1 − 16 + 9 = −6.
  5. cos φ = −6/26 = −3/13.
cos φ = −3/13 ≈ −0.23

Angle in a cube

ABCDA₁B₁C₁D₁ is a cube. Find the angle between AB and A₁C₁.

  1. A₁C₁ = AC (same direction and length, the top face is a copy of the bottom).
  2. So we need the angle between AB and the diagonal AC of square ABCD.
  3. A diagonal of a square cuts the 90° corner in half → 45°.
  4. With coordinates: AB = (1; 0; 0), AC = (1; 1; 0), cos φ = 1/√2 → 45° ✓
45°

Three vectors at 120°

p, q, r start at one point, each pair makes 120°, |p| = 3, |q| = 6, |r| = 2. Express r with p and q.

  1. Three unit vectors at 120° to each other add up to zero (they form a closed equilateral triangle).
  2. Unit vectors: p/3, q/6, r/2 → p/3 + q/6 + r/2 = 0.
  3. Multiply by 2: r = −(2/3)·p − (1/3)·q.
  4. Check with lengths: |r|² = (4/9)·9 + (1/9)·36 + 2·(2/9)·(3·6·cos120°) = 4 + 4 − 4 = 4 → |r| = 2 ✓
r = −⅔·p − ⅓·q
