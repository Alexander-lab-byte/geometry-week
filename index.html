Problem 1

R = 4, ABCDE inscribed, AB = 4√2, ∠ABE = 45°, ∠EBD = 30°, BC = CD. Find the area.

  1. Law of sines: AB = 2R·sin∠AEB → 4√2 = 8·sin∠AEB → ∠AEB = 45° → arc AB = 90°.
  2. Inscribed angle = half its arc: ∠ABE = 45° → arc AE = 90°.
  3. ∠EBD = 30° → arc ED = 60°.
  4. arc BC + arc CD = 360° − 90° − 90° − 60° = 120°. BC = CD → arc BC = arc CD = 60°.
  5. Cut the pentagon into 5 triangles from O. Each: S = ½R²·sin φ = 8·sin φ.
  6. S = 8·sin90° + 8·sin90° + 3·8·sin60° = 8 + 8 + 12√3.
Answer: S = 16 + 12√3 ≈ 36.8

Problem 2

AB is tangent, OB meets the circle at C, ∠AOC = 60°, sector area = 2π/3. Find S(AOB).

  1. Sector area: (60°/360°)·πr² = 2π/3 → πr²/6 = 2π/3 → r² = 4 → r = OA = 2.
  2. A tangent is perpendicular to the radius → ∠OAB = 90°.
  3. In right triangle OAB: AB = OA·tan60° = 2√3.
  4. S = ½·OA·AB = ½·2·2√3.
Answer: S = 2√3 ≈ 3.46

Problem 3

Right triangle, legs 15 and 8. Find the radius of the inscribed circle.

  1. Hypotenuse: c = √(15² + 8²) = √289 = 17.
  2. Incircle of a right triangle: r = (a + b − c)/2 = (15 + 8 − 17)/2 = 3.
  3. Check: r = S/p = 60/20 = 3 ✓ (S = ½·15·8 = 60, p = 40/2 = 20).
Answer: r = 3

Problem 4

AB = 2, ∠A = 45°, ∠B = 75°, H is the orthocenter. Find AH.

  1. ∠C = 180° − 45° − 75° = 60°.
  2. Law of sines: 2R = AB/sin C = 2/(√3/2) = 4/√3.
  3. Vertex-to-orthocenter rule: AH = 2R·cos A.
  4. AH = (4/√3)·(√2/2) = 2√2/√3 = 2√6/3.
  5. Check with coordinates A(0;0), B(2;0): H ≈ (1.577; 0.423), AH ≈ 1.633 ✓
Answer: AH = 2√6/3 ≈ 1.63

Problem 5

ABCD inscribed, CD = √2, ∠CAD = 45°. Find the circumradius R.

  1. ∠CAD is inscribed and stands on chord CD → central angle ∠COD = 2·45° = 90°.
  2. OC = OD = R, so in right triangle COD: CD² = R² + R² → CD = R√2.
  3. R√2 = √2 → R = 1.
  4. Check: CD = 2R·sin45° → √2 = 2R·(√2/2) → R = 1 ✓
Answer: R = 1

Problem 6

Isosceles trapezoid. A diagonal cuts the midline into 2 cm and 5 cm. Leg = 6 cm. Find the acute angle.

  1. Each piece of the midline is a midline of a small triangle, so it is half of a base.
  2. Small base DC = 2·2 = 4, big base AB = 2·5 = 10.
  3. Draw the height DH. Isosceles → AH = (10 − 4)/2 = 3.
  4. In right triangle ADH: cos∠A = AH/AD = 3/6 = 1/2 → ∠A = 60°.
Answer: 60°

Problem 7

Right triangle, legs in ratio 1 : 3, area 15. Find the area of the circumscribed disk.

  1. Legs x and 3x: ½·x·3x = 15 → x² = 10.
  2. c² = x² + 9x² = 10x² = 100 → c = 10.
  3. In a right triangle the hypotenuse is a diameter → R = 5.
  4. S = πR² = 25π.
Answer: 25π ≈ 78.5

Problem 8

AB = BC, ∠B = 90°, EC/BC = 1/3, S(AEC) = 24 cm². Find AB.

  1. Let AB = BC = a. Then EC = a/3.
  2. In triangle AEC take EC as the base. Its height is AB, because AB ⊥ BC.
  3. S(AEC) = ½·(a/3)·a = a²/6.
  4. a²/6 = 24 → a² = 144 → a = 12.
Answer: AB = 12 cm

Problem 9

Square ABCD, side 4 m. M = midpoint of AB, O = center. Find the radius of the circle through M, O, C.

  1. Coordinates: A(0;0), B(4;0), C(4;4) → M(2;0), O(2;2).
  2. Center K(x;y). KM = KO and M, O both have x = 2 → y = 1.
  3. KO = KC: (x−2)² + 1 = (x−4)² + 9 → 4x = 20 → x = 5. So K(5;1).
  4. R² = KM² = 3² + 1² = 10 → R = √10.
  5. Check: MC = 2√5, ∠MOC = 135°, R = MC/(2·sin135°) = √10 ✓
Answer: R = √10 ≈ 3.16 m

Problem 10

AC = 9 m, ∠B = 60°, O = incenter. Find the radius of the circle through O, A, C.

  1. The incenter lies on the angle bisectors: ∠OAC = ∠A/2, ∠OCA = ∠C/2.
  2. ∠A + ∠C = 180° − 60° = 120°.
  3. ∠AOC = 180° − 120°/2 = 120° (rule: ∠AOC = 90° + ∠B/2).
  4. Law of sines in AOC: R = AC/(2·sin120°) = 9/√3 = 3√3.
Answer: R = 3√3 ≈ 5.2 m

Problem 11

Rhombus: (sum of diagonals) / (perimeter) = 1/√2. Find the acute angle.

  1. Side a, angle α. The diagonals are perpendicular and bisect each other: d₁ = 2a·cos(α/2), d₂ = 2a·sin(α/2).
  2. (d₁ + d₂)/(4a) = (cos(α/2) + sin(α/2))/2 = 1/√2.
  3. cos(α/2) + sin(α/2) = √2.
  4. Use cos t + sin t = √2·sin(t + 45°): sin(α/2 + 45°) = 1 → α/2 + 45° = 90° → α = 90°.
Answer: α = 90° (the rhombus is a square)

A square has no acute angle, so the problem probably has a typo. With the numbers given, 90° is the only solution, because √2 is the largest value of cos t + sin t. Ask your teacher.

Problem 12

AC passes through center O, PA and PB are tangents, ∠APC = 40°. Find ∠ABC = x.

  1. Tangents from one point are equal: PA = PB → triangle APB is isosceles.
  2. ∠PAB = ∠PBA = (180° − 40°)/2 = 70°.
  3. C, B, P are on one line, so ∠ABC + ∠ABP = 180° → x = 180° − 70° = 110°.
  4. Check: OA ⊥ PA → ∠CAP = 90°, ∠ACP = 50°, ∠BAC = 90° − 70° = 20° → x = 180° − 20° − 50° = 110° ✓
Answer: ∠ABC = 110°

Problem 13

MQ is a median, MP = 2√3, NP = 8, ∠QMP = 45°. Find S(MNP).

  1. Q is the midpoint of NP → QP = NQ = 4.
  2. Law of cosines in MQP, MQ = m: 16 = m² + 12 − 2·m·2√3·cos45° → m² − 2√6·m − 4 = 0.
  3. m = √6 ± √10. m > 0 → MQ = √6 + √10.
  4. S(MQP) = ½·MQ·MP·sin45° = (√6 + √10)·√6/2 = (6 + 2√15)/2 = 3 + √15.
  5. A median splits the triangle into two equal areas → S(MNP) = 2·(3 + √15).
Answer: S = 6 + 2√15 ≈ 13.75

Problem 14

Secants PB and PA meet the circle at C and D. ∠ABC = 90°, BC = CP, AD = 6 cm, DP = 4 cm. Find R.

  1. ∠ABC = 90° is inscribed → it stands on a diameter → AC = 2R.
  2. Secant rule: PC·PB = PD·PA. Let BC = CP = x, so PB = 2x and PA = 10.
  3. x·2x = 4·10 → x² = 20 → x = 2√5, PB = 4√5.
  4. Right triangle ABP: AB² = PA² − PB² = 100 − 80 = 20.
  5. Right triangle ABC: AC² = AB² + BC² = 20 + 20 = 40 → AC = 2√10.
  6. R = AC/2 = √10.
Answer: R = √10 ≈ 3.16 cm

Problem 15

Altitudes from A and C meet at H. Circumradius R = 4, sin∠BAH = 2/5. Find BH.

  1. AK is an altitude, so in right triangle ABK: ∠BAH = ∠BAK = 90° − ∠B.
  2. So cos B = sin(90° − B) = sin∠BAH = 2/5.
  3. Vertex-to-orthocenter rule (same as problem 4): BH = 2R·cos B.
  4. BH = 2·4·(2/5) = 16/5.
Answer: BH = 16/5 = 3.2

Problem 16

Right trapezoid (∠BAD = 90°) with an inscribed circle. The circle touches leg CD at E, CE = 4, DE = 7. Find r.

  1. BC ∥ AD, so ∠C + ∠D = 180°.
  2. The center O is on the bisectors of ∠C and ∠D, so ∠OCD + ∠ODC = 90° → ∠COD = 90°.
  3. The radius to the touching point is perpendicular to the tangent: OE ⊥ CD. So OE is the height to the hypotenuse of right triangle COD.
  4. Height to the hypotenuse: OE² = CE·DE → r² = 4·7 = 28 → r = 2√7.
  5. Check: AD = r + 7, BC = r + 4, height 2r. CD² = 3² + (2r)² = 9 + 112 = 121 → CD = 11 = 4 + 7 ✓
Answer: r = 2√7 ≈ 5.29

Problem 17

Isosceles triangle, AB = BC = 8, base angle π/6. Find the area.

  1. π/6 = 30°, so ∠A = ∠C = 30°.
  2. Angle at the top: ∠B = 180° − 2·30° = 120°.
  3. S = ½·AB·BC·sin B = ½·8·8·sin120° = 32·(√3/2) = 16√3.
  4. Check: height h = 8·sin30° = 4, base AC = 2·8·cos30° = 8√3, S = ½·8√3·4 = 16√3 ✓
Answer: S = 16√3 ≈ 27.7

Problem 18

Altitude BD splits AC into AD = 5 and DC = 9. E is on BD with BE : ED = 4 : 5, BD = 12. Find S(ABE) : S(DEC).

  1. BD = 12 is 9 parts: one part = 12/9 = 4/3 → BE = 16/3, ED = 20/3.
  2. Triangle ABE: base BE lies on BD, and its height is the distance from A to BD, which is AD = 5 (because BD ⊥ AC).
  3. S(ABE) = ½·(16/3)·5 = 40/3.
  4. Triangle DEC: right angle at D, legs ED = 20/3 and DC = 9 → S(DEC) = ½·(20/3)·9 = 30.
  5. Ratio: (40/3) : 30 = 40 : 90 = 4 : 9.
Answer: S(ABE) : S(DEC) = 4 : 9

Problem 19

A, B, C, D are on a circle, chords AC and BD meet at E. ∠BAE = 40°, ∠BEC = 70°. Find ∠DCE = x.

  1. ∠BEC is an exterior angle of triangle ABE, so it equals the sum of the two far angles: ∠BEC = ∠BAE + ∠ABE.
  2. 70° = 40° + ∠ABE → ∠ABE = ∠ABD = 30°.
  3. ∠ABD and ∠ACD are inscribed angles on the same arc AD, so they are equal.
  4. x = ∠DCE = ∠DCA = ∠ABD = 30°.
Answer: ∠DCE = 30°

Problem 20

A, B, C are on a circle, PA and PB are tangents, PA = 6 cm, ∠ACB = 60°. Find the length of arc AB that ∠ACB stands on.

  1. Inscribed angle = half its arc: ∠ACB = 60° → arc AB = 120°, so ∠AOB = 120°.
  2. Tangents are perpendicular to radii: ∠OAP = ∠OBP = 90°. In quadrilateral OAPB: ∠APB = 360° − 90° − 90° − 120° = 60°.
  3. PO bisects ∠APB, so ∠APO = 30°. In right triangle OAP: R = OA = PA·tan30° = 6/√3 = 2√3.
  4. Arc length: L = R·θ, with θ = 120° = 2π/3. L = 2√3·(2π/3) = 4√3π/3.
Answer: arc AB = 4√3π/3 ≈ 7.26 cm

Here "arc length" means the length along the circle, not the chord. The chord is AB = 6, because triangle PAB is equilateral.
